# РемонтСмета 1.0

**[Открыть приложение](https://muzzikon.github.io/RemontSmeta/)** · [Исходный код](https://github.com/Muzzikon/RemontSmeta)

Сайт работает на GitHub Pages. Компьютер автора, терминал и ChatGPT для его работы не нужны. Пользователь открывает ссылку в браузере.

Веб-приложение для бюджета ремонта. Пользователь открывает опубликованный HTTPS-адрес в современном браузере. Установка Node.js нужна только разработчику.

Смета хранится в LocalStorage, фото чеков — в IndexedDB текущего профиля браузера. Нет автоматической синхронизации. Полная копия .rmsbackup переносит смету и фото, поддерживается импорт старого JSON. Очистка данных сайта удаляет локальные записи.

Возможности: комнаты, работы и материалы, платежи, чеки JPEG/PNG/WebP/HEIC, сводка и пороги 90/100 процентов, CSV, печать/PDF, тёмная/светлая/системная тема. PWA работает офлайн после первого успешного кэширования; установка на устройство необязательна.

Разработка: npm ci, npm run dev. Проверка: npm test, npm run build. Размещать содержимое dist на HTTPS-хостинге; не открывать index.html через file://. Для конкурентной записи используется Web Locks. Рекомендуются актуальные Chrome и Edge.

Перенос из Windows-сборки: сохранить полную копию в EXE, открыть сайт, Файлы → Восстановить из копии. Импорт после проверки заменяет текущую смету с явным подтверждением.

## Запуск проекта из репозитория

Требуется Node.js 22.18 или новее.

```sh
npm ci
npm run dev
```

Откройте адрес, который выведет Vite (обычно http://localhost:5173). Двойной щелчок по index.html не запускает проект.

## Сборка и проверка

```sh
npm test
npm run build
npm run preview
```

Готовые файлы появятся в dist. Их можно разместить на HTTPS-хостинге со статическими файлами. Веб-приложение не использует серверную базу данных. Базовый путь уже настроен для GitHub Pages по адресу /RemontSmeta/.

Проверены 88 автоматических тестов. Ограничения: один активный ремонт, нет облачной синхронизации, офлайн зависит от доступности Service Worker. На GitHub Pages проверены кэширование приложения и статус «Офлайн готов».

## Публикация на GitHub Pages

Основной сайт: https://muzzikon.github.io/RemontSmeta/

При изменениях в main GitHub Actions запускает тесты, собирает проект и публикует dist. В Settings → Pages выбран источник GitHub Actions. Базовый путь /RemontSmeta/ задан в vite.config.ts; значки, шрифты, Web Worker и Service Worker загружаются из папки проекта.

Данные со старого адреса автоматически не переносятся. На старом сайте сохраните полную копию .rmsbackup, затем восстановите её на новом через «Файлы → Восстановить из копии».
